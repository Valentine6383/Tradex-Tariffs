# K2 Widget

Мини-плеер для 3D-принтера Creality K2 (и других K-серии) под Windows: висит в углу экрана поверх окон,
сам всплывает, когда идёт печать, и прячется в трей, когда принтер стоит.

- прогресс, время до конца и во сколько закончит, слой, температуры, скорость и поток, расход пластика;
- регулировка скорости (пресеты 50/100/130/160%) и вентиляторов;
- пауза / продолжить / стоп;
- «Не печатать» для отдельной детали (EXCLUDE_OBJECT);
- автопоиск принтера в сети, автозапуск с Windows.

Связь — по локальной сети через WebSocket `ws://<IP принтера>:9999` (тот же канал, что у Creality Print).

## Разработка
```
npm install
npm run mock     # фейковый принтер на 127.0.0.1:9999
npm start
npm run dist     # сборка под Windows в dist/
```
